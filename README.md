# साहित्य ग्राम — पहला चलने योग्य प्रोटोटाइप

यह एक शुरुआती, मोबाइल-अनुकूल PWA प्रोटोटाइप है। अभी इसमें:
- मुख्यपृष्ठ और श्रेणी फ़िल्टर
- नमूना रचनाएँ
- रचना लिखना और प्रकाशित करना
- डिवाइस पर ऑटो-सेव ड्राफ्ट
- प्रोफ़ाइल परिचय (अधिकतम 1,000 अक्षर)
- रचना पढ़ना, अनुमानित पढ़े शब्द दर्ज करना और बुकमार्क
- डार्क/ब्राइट मोड
- ऑफलाइन ऐप शेल (PWA)

## इसे चलाने का सबसे आसान तरीका

### विकल्प A: कंप्यूटर पर
1. ZIP फ़ाइल को अनज़िप करें।
2. उस फ़ोल्डर में टर्मिनल खोलें।
3. Python उपलब्ध हो तो चलाएँ:
   ```bash
   python -m http.server 8080
   ```
4. ब्राउज़र में `http://localhost:8080` खोलें।

सिर्फ़ `index.html` पर डबल-क्लिक करके भी UI खुल सकता है, लेकिन PWA/offline सुविधाओं के लिए HTTP सर्वर चाहिए।

### विकल्प B: Android फोन पर
PWA इंस्टॉल करने के लिए इस फ़ोल्डर को HTTPS पर होस्ट करना होगा। फिर Chrome में वेबसाइट खोलकर ब्राउज़र मेनू से **Install app / Add to Home screen** चुनें। ZIP को सीधे फोन में खोलना पूर्ण इंस्टॉल नहीं है।

## अभी क्या डेमो है, क्या असली नहीं?
यह पहला स्थानीय प्रोटोटाइप है। डेटा `localStorage` में रहता है:
- दूसरे डिवाइस पर अपने-आप नहीं पहुँचेगा।
- अभी असली Gmail/Zoho/Facebook लॉगिन नहीं है।
- संदेश, सार्वजनिक सर्वर प्रकाशन, वास्तविक फ़ॉलो सिस्टम, रेटिंग/समीक्षा, एडमिन सर्वर, और सुरक्षित अकाउंट डिलीशन अभी नहीं जुड़े।
- पढ़े शब्दों की संख्या केवल मोटा अनुमान है, प्रमाणित पढ़ने का माप नहीं।
- ब्राउज़र में स्क्रीनशॉट/कॉपी को पूरी तरह रोकने का दावा नहीं किया गया है।

## अगला चरण: साझा बैकएंड
`backend/supabase_schema.sql` में शुरुआती Supabase डेटाबेस स्कीमा है। अगली अवस्था में:
1. Supabase प्रोजेक्ट बनाना।
2. SQL स्कीमा चलाना।
3. Authentication और Row Level Security (RLS) नीतियाँ लगाना।
4. वेबसाइट को Supabase से जोड़ना।
5. उसी वेब ऐप को Capacitor के माध्यम से Android पैकेज में लपेटना।

Supabase की मुफ्त योजना की सीमाएँ होती हैं; वर्तमान सीमा और उपलब्धता अकाउंट बनाते समय जाँचें। किसी भी सेवा की चाबी सार्वजनिक GitHub या ऐप के कोड में न डालें।

## साझा तकनीकी ढाँचा
- फ्रंटएंड: HTML/CSS/JavaScript (पहला प्रोटोटाइप)
- वेबसाइट: PWA
- Android: अगले चरण में Capacitor wrapper
- बैकएंड का प्रस्ताव: Supabase (PostgreSQL + Auth + Storage)
- वेबसाइट और Android दोनों एक ही API/डेटाबेस का इस्तेमाल करेंगे।

## फ़ोल्डर
- `index.html` — ऐप स्क्रीन
- `styles.css` — दृश्य डिज़ाइन और responsive layout
- `app.js` — प्रोटोटाइप लॉजिक
- `manifest.webmanifest` और `sw.js` — PWA स्थापना/offline shell
- `backend/supabase_schema.sql` — बैकएंड का शुरुआती डेटाबेस ढाँचा
